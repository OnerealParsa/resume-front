# Resume Frontend

The frontend of my personal resume website — vanilla HTML, CSS and JavaScript, deployed with GitHub Pages.

**Live:** https://onerealparsa.github.io/resume-front/

## Features

- Typing effect for the headline
- Dark / light theme with `localStorage` persistence and automatic `prefers-color-scheme` detection
- No frameworks, no build step

## Project Structure

| File | Purpose |
|---|---|
| `index.html` | Page markup |
| `style.css` | Styling and theme variables |
| `script.js` | Typing effect and theme switching |

## Deploy

The site is served with GitHub Pages from the `main` branch.
